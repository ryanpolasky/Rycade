# Rycade technical notes

How Rycade is put together, how to run it, and how to drive it. For the showcase, see the [README](../README.md).

## Repo layout

| Path | What it is |
| --- | --- |
| `public/` | The whole frontend: static HTML/CSS/JS with no build step, plus art, demo clips and the vendored EmulatorJS |
| `public/games.js` | The catalog: one entry per game with system, players, controls, art paths and accent colors |
| `public/emulation.js` | Per-game core, ROM lookup and input data (generated by `tools/generate-emulation.js` from the catalog and [SOURCING.md](../SOURCING.md)) |
| `public/play.html`, `public/play.js` | The in-page EmulatorJS player that runs in a fullscreen layer over the menu |
| `public/themes/`, `public/themes.js` | Cover Flow, Shelf and Studio |
| `public/boot.js`, `public/boot/` | Canvas boot scenes and their audio |
| `public/remote/`, `public/scores/` | Phone remote and the public high-score page |
| `src/worker.js` | Cloudflare Worker: serves `public/`, relays the phone remote and stores scores |
| `mac/` | Mac mini cabinet setup (kiosk, firewall, power slider, remote access); see [mac/README.md](../mac/README.md) |
| `firmware/` | Raspberry Pi Pico firmware that turns the control deck into USB pads; see [firmware/README.md](../firmware/README.md) |
| `docs/nba-jam-joystick-board.md` | Reverse-engineered protocol of the Arcade1Up NBA Jam joystick board |
| `SOURCING.md` | ROM checklist: exact MAME sets and No-Intro names, cores and per-game control notes |
| `tests/` | Node tests for attract mode, emulation lookup, pads, profiles, high scores and the player |

## Controls

`public/pads.js` maps every pad to these same keys, so a keyboard works the same as the cab.

- Left / Right: browse the flyers; hold to repeat and skim by letter. Pause on a game (or press Down) to open its details.
- Up: move into the top bar. Left / Right picks search, a category, or settings; SHOOT selects it; Down goes back to the games.
- Categories: ALL, ★ FAVORITES, 2P+ (2 or more players), 4P (4 or more players), then each system.
- Z / C: switch categories directly.
- In settings, Left from the section list closes it. In search, DONE closes it.
- Enter (START): launch the selected game, including while watching its demo. Escape exits a launched game.
- In cab mode, the seat that starts a 1–3-player game becomes P1; the next different seats to press START join as P2, then P3. Games with 4+ players or unknown player counts keep fixed seats.
- In cab mode, Smash TV pairs seats 1/2 and 3/4 as each player's twin sticks (Robotron's alternating turns both use seats 1/2), with START on either stick of a pair; Q*bert's diagonal four-way rotation is automatic.
- 1 / 2 / 3: SHOOT / PASS / TURBO. SHOOT (1) opens the selected game's video demo; SHOOT again or Escape returns to the menu.
- PASS (2) or F: favorite or unfavorite the selected game. Favorites live in the ★ FAVORITES tab and persist in the browser.
- TURBO (3) or R: spin a reel of the current tab's box art that lands on a random game. START plays it, TURBO spins again, PASS or Escape backs out.
- Click or tap a flyer to select it, tap it again or the game screen to launch, and tap while launched to exit.
- `/` or `S`: search the library; `M`: open settings. Settings persist in the browser.
- Use the Phone Remote section in settings to scan the pairing QR code and send a game selection from your phone.
- Attract mode starts after 2 minutes idle and shuffles full-screen game demos without repeats. Settings > Display offers Off / 1 / 2 / 5 minutes. Any input returns to browsing; START selects the game shown without launching it. Attract clips are muted; manual demos keep their existing audio controls. Settings, search, demos, launched games and boot previews suspend the idle countdown. Gamepad buttons/sticks wake it (standard gamepad START is button 9).
- Reduced motion uses still gameplay snaps and a steady START prompt during attract mode, keeping the same clip-length rotation.
- Settings > Boot > Play boot now previews the selected scene. Boot scenes are rendered live in `public/boot.js`, clocked to `public/boot/rycade.wav`, with the big reveal on the 4.44s synth hit. Each intro plays once, then holds its title screen with ambient motion until a key or click dismisses it; that input is consumed. Reduced motion shows the finished title screen. Boot audio follows master volume and mute.

## Emulation

Games run inside the page with a vendored [EmulatorJS](https://emulatorjs.org) 4.2.3 (`public/vendor/emulatorjs/`), so launching and exiting never leave the window.

| System | Core |
| --- | --- |
| Arcade | `mame2003_plus` |
| Genesis | `genesis_plus_gx` |
| SNES | `snes9x` |
| NES | `fceumm` |
| GBA | `mgba` |

ROMs are not in this repo. The player looks for them under `/roms/<arcade|genesis|snes|nes|gba>/` (it reads a JSON directory listing for each system), plus an optional `/roms/overrides.json` that maps a ROM filename to a different core. Name files by the MAME set or No-Intro name in [SOURCING.md](../SOURCING.md).

- **Boot skip.** MAME games that show their own boot test or warning screen are fast-forwarded muted behind the loading cover (`bootSkipFrames`, 900 frames by default, per-game `BOOT_FRAMES`, 15 s cap).
- **Game CRT.** Every game gets EmulatorJS's bundled `crt-easymode.glslp` shader, set in `EJS_onGameStart` so it overrides any per-game EmulatorJS settings saved earlier. Settings > Display > CRT in games turns it off (the menu passes `crt=0` to `play.html`).
- **Input layouts.** `INPUT_LAYOUTS` / `CORE_OPTIONS` / `RETRO_REMAPS` in `public/play.js` handle twin-stick games, Q*bert's four-way rotation and NES Four Score titles.
- **Profiles and saves.** Before a battery-save game (`SAVE_GAMES` in `public/profiles.js`), players pick initials, and each profile's SRAM is swapped in and out of `/data/saves/rycade/<profileId>/<gameId>.srm`.
- **High scores.** `public/hiscores.js` decodes `.hi` / NVRAM tables for supported arcade games and queues new entries. Uploads carry only `{game, entries: [{initials, score}]}`.

## Demo videos

Real gameplay/attract video snaps are bundled for every library entry in `public/videos/<game-id>.mp4`, for example `public/videos/jamte.mp4`. Sources and encoding details are recorded in `public/videos/sources.json`. Clips are approximately 25 seconds, H.264 + AAC, at most 480 pixels wide, with faststart and a short fade through black at the loop boundary. A game's optional `video` field can override that path for another video format or location.

SHOOT opens a looping, full-screen demo. SHOOT or Escape closes it; START stops the demo and launches the selected game. Missing or unplayable clips return to the menu with an unavailable message. Demo audio follows the master volume and mute setting.

Box art, flyers, logos and snaps come from libretro-thumbnails and flyer archives; portrait crops and replacements are logged in `public/art/portrait-sources.json`.

## Audio

Navigation and feedback sounds are synthesized in-browser with the Web Audio API in the Cabinet, Chip, and Neo sound sets. Boot previews use the supplied `rycade.wav` and `rycadeping.wav` recordings. Both files share one timeline: `rycadeping.wav` already has 4.44 seconds of leading silence, so it plays in sync with `rycade.wav` at 32% level, skipping a 25ms click at 4.44s. It keeps its recorded fade-in and fades out over its final eight seconds, ending around 48.84 seconds into the sequence.

## Worker

`src/worker.js` serves `public/` as static assets and handles:

| Route | Does |
| --- | --- |
| `GET /api/ws?code=…` | WebSocket into the `Room` Durable Object for a six-character pairing code (the cab listens) |
| `POST /api/send` | Phone remote sends a game selection to a room |
| `GET /api/scores` | All high-score boards (`Scores` Durable Object) |
| `POST /api/scores` | Add entries; needs `Authorization: Bearer <SCORE_KEY>` |
| `/remote`, `/scores` | The phone remote and scoreboard pages |

## Cab mode

On the cabinet, Chrome runs as a kiosk on `http://127.0.0.1:8787/?cab=1`, served by Caddy from a local checkout. `public/cab.js` preloads all art and demo clips into memory, turns off the phone remote, and listens for power events from `rycade-power`. Setup, the firewall modes, remote access and updates are covered in [mac/README.md](../mac/README.md).

The control deck connects through a Pico running the firmware in [firmware/](../firmware/README.md). It reads the deck's two UART links and exposes one combined 4-player pad (split back into "Rycade P1–P4" by `public/padsplit.js`) plus a "Rycade Cabinet" keyboard for power (F17/F18), LIVE (F19) and volume.

## Develop

Serve `public/` with any static server for the menu, or run the Worker locally with its Durable Objects:

```sh
npx wrangler dev
```

Tests:

```sh
node --test tests/*.test.cjs
make -C firmware/test
```

## Deploy

```sh
npx wrangler deploy
```

Pushes to `main` also deploy automatically through Cloudflare Workers Builds. Other branches deploy to the `rycade-preview` Worker.
